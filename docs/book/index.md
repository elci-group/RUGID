## Preface

Welcome to RUGID. If you are reading this, you are likely tired of CSS `z-index` wars, confused by `flex-grow` vs `flex-shrink`, or just want to build user interfaces that feel like living organisms rather than static documents.

RUGID is not just a UI engine; it is a simulation. It treats every UI element as a "Cell" living in a relativistic space. There is no "top-left" of the screen. There is only "relative to my parent". 

This book will guide you from "Hello World" to building complex, 3D-accelerated, physics-enabled interfaces using the RUGID Definition Format (RDF).

Buckle up. It's going to be a relativistic ride.
